To refresh: launch the current native EXE, set Settings to English, select a game
installation, and open a disposable copy of the sample. Maximize the window.
Under Heroes enable Owned only, select Moandor, then Army. Under Towns choose
Winter Palace and capture Buildings and Mage Guild separately. Under Players
select Red and capture Resources and Exploration. Under Creatures select Wandering
creatures, sort quantity descending and open Filter. Keep Details and Advanced /
Diagnostics collapsed. Review for private information and missing artwork before
replacing the images. Do not save edits to the original sample.
