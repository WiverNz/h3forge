# README screenshots

Captured on 2026-11-11 from the actual H3Forge 0.1.0 portable Windows EXE using
Windows UI Automation and native screen capture. The application window was
1400 x 900; the captured client area is 1384 x 861. These are not browser previews
or mockups. Interface language: English. Theme: dark.

| File | View |
|---|---|
| [hero-army.png](hero-army.png) | Zehirmahnn's seven army slots, with owned heroes in the sidebar |
| [town-buildings.png](town-buildings.png) | Corral's building cards, including unsupported locked structures |
| [town-mage-guild.png](town-mage-guild.png) | Corral's five populated Mage Guild spell levels |
| [player-resources.png](player-resources.png) | Red player's resources, with player status and map information |

The sample was copied to an ignored fixture before opening. No save operation was
performed. Game resources were read from the existing installation; no archives
or standalone extracted artwork are included here. Only the application client
area is captured, excluding the desktop, dialogs and private filesystem paths.
PNG encoding was optimized without changing the captured RGB pixels.

To refresh: launch the current native EXE, set Settings to English, select a game
installation, and open a disposable copy of the sample. Set the window near
1400 x 900. Under Heroes enable Owned only, select Zehirmahnn, then Army. Under
Towns choose Corral and capture Buildings and Mage Guild separately. Under Players
select Red and Resources. Keep Details and Advanced / Diagnostics collapsed,
close menus/dialogs, move the pointer away from content, and capture the client
area. Review for private information and missing artwork before replacing these
four files. Do not save edits to the original sample.
