Status: complete (2026-11-14), with pre-existing private-fixture limitations below.

## Scope

release workflow installation pin, and current development/architecture/release

source, save format, parsing, patching or serialization behavior changes.

## Private save regression evidence

The additional workspace run uses absolute `games/`, `Maps/` and `Data/` paths
and `--no-fail-fast -- --nocapture`. The resource crate interprets the fixture
root as an archive directory, so its initial missing-archive failures were
resolved by the separate `Data/` run above.

The supplied current saves pass native CRC import/preservation, mana-only
patching, Save/Save As/backup/reopen, and 224 isolated player-resource round trips.
Equipment equip/unequip and reservation-counter checks pass across all 12 saves.
All 64 tent-bit edit/serialize/reopen/restore cases and the Xyron army round trip
pass. Synthetic parser, checked patch and gzip serialization tests pass.

Historical sample tests expect absent coordinate/dismissal pairs, old sample
counts, or the old hero span 4,727,078. Direct-save and coordinate failures, plus
the completed desktop and core fixture failures, reproduce under Rust 1.99.1
with the same locked dependencies (`--ignore-rust-version` only bypasses the new
workspace MSRV for this baseline). The old `edit_flow::candidate_id` searches an
unbounded ID range for that missing span; its stalled process was stopped so
the other suites could continue. No test expectations or application logic were
altered to hide these fixture limitations.

The fixture-enabled workspace run finishes with 32 failed targets: nine archive
targets pass on rerun with the correct `Data/` root; 22 save/desktop targets also
fail on Rust 1.99.1; one `edit_flow` target was stopped for the unbounded search
described above. Missing dismissal pairs also cause explicit skips. This is not
a fully green private-fixture suite, and migration completion does not claim
otherwise. Restoring historical fixtures or repairing their assumptions is a
separate task.

Cargo metadata confirms all four workspace members inherit MSRV 1.100.0.
Both lockfiles are byte-for-byte unchanged in Git, and `git diff --check` passes.
No compatibility source changes were required.

Native application interaction,
in-game loading and remote GitHub Actions execution are not revalidated here;
the exact local production script used by CI passed.

Validation logs are ignored under `.local/rust-1.100-*.log`. Node test and Vite
subprocesses required execution outside the sandbox after Windows `spawn EPERM`.
No dependencies were installed or upgraded.
